Tutorials
=========

These notebooks are rendered with the outputs they had when they were last run.
They are **not executed** during the documentation build, because most of them
need simulation data that is not publicly downloadable. To reproduce them, open
the ``.ipynb`` file from ``docs/source/tutorials/`` in Jupyter and point the
configuration file at your own data.
